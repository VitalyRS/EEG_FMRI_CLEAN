# EEG Compare & Visualizer GUI

Интерактивное графическое приложение (GUI) на **PyQt5**, **MNE-Python** и **Matplotlib** для визуального и количественного сравнения двух файлов ЭЭГ.

## Поддерживаемые форматы
- **MNE FIF**: `.fif`, `.fif.gz`
- **EEGLAB**: `.set` (с `.fdt`)

---

## Основные возможности

1. **Загрузка двух файлов**:
   - Можно открыть через диалоговое окно (кнопки «Файл 1», «Файл 2») или передать путями в аргументах командной строки.
   - Отображаются частота дискретизации $F_s$, длительность и количество каналов для каждого файла.

2. **Наложение сигналов (Overlay)**:
   - **Режим «Наложение (Overlay)»**: сигналы Файла 1 (синий) и Файла 2 (оранжевый) отображаются на одних осях с настраиваемой прозрачностью, что позволяет сразу увидеть разницу до/после очистки (например, BCG, ICA) или форму артефактов.
   - **Режим «Разница (File 1 - File 2)»**: вычитание сигналов в реальном времени с нулевой изолинией.
   - **Режим «Раздельно (Split)»**: отображение обоих сигналов со смещением по вертикали.

3. **Интерактивный сдвиг во времени (Time Shift)**:
   - Сдвиг Файла 2 относительно Файла 1 с настраиваемым шагом: **50 мс** (по умолчанию), а также **10, 100, 200, 500, 1000 мс**.
   - Кнопки пошагового сдвига `[◄ -50 мс]`, `[+50 мс ►]` и сброса в ноль `[0 мс]`.
   - Точный ввод сдвига в миллисекундах и секундах.
   - Кнопка **«⚡ Автосдвиг»** — автоматический подбор лага по максимуму взаимной корреляции (в диапазоне ±1 сек).

4. **Обрезание графиков (Trimming) и расчет корреляции по кусочкам**:
   - Чекбокс **«Включить обрезку графиков»**.
   - Для **Файла 1**: отсечение с начала ($T_{start1}$ с) и с конца ($T_{end1}$ с).
   - Для **Файла 2**: отсечение с начала ($T_{start2}$ с) и с конца ($T_{end2}$ с).
   - Наглядная подсветка отсеченных областей на графике красной полупрозрачной штриховкой `//`.
   - Кнопка **«📊 Рассчитать корреляцию по кусочкам»** — открывает модальное окно с:
     - Общей средней корреляцией Pearson $r$ и RMSE.
     - Диапазоном $r$ (Min / Max).
     - Поканальной таблицей с цветовой градацией качества (зеленый $r \ge 0.8$, желтый, красный).
     - Экспортом таблицы в CSV файл.

5. **Выбор и фильтрация каналов**:
   - **Клик в любую часть строки** (по тексту, названию или галочке) моментально включает или выключает канал.
   - **Пробел (Space)** на выделенной строке переключает канал.
   - **Двойной клик на канале** активирует режим **Solo** (оставляет только этот один канал и показывает его крупно).
   - **Правый клик (контекстное меню)**: «Только этот канал (Solo)», «Переключить», «Включить/отключить все видимые в фильтре».
   - Кнопка **«Снять все»** — моментально очищает график, после чего можно включать нужные каналы кликами.
   - Кнопка **«Все общие»** — восстанавливает выбор всех общих каналов.
   - Текстовый фильтр/поиск каналов (например `Fz`, `Cz`).
   - Настройка числа каналов на экране: **8, 16, 24, 32 или Все**.
   - Пагинация страниц каналов (кнопки «▲ Пред.» / «▼ След.»).

5. **Отображение меток и событий (Markers / Annotations / Triggers)**:
   - Автоматическое считывание встроенных меток из `raw.annotations` и триггеров из стимульных каналов.
   - Автопоиск сопутствующих файлов меток (`*_events.tsv`, `.vmrk`, `.csv`) рядом с файлами записи.
   - Кнопка **«+ Из файла...»** для ручной загрузки внешнего файла меток к любому из файлов.
   - Раздельное включение/выключение меток Файла 1 (голубой пунктир) и Файла 2 (оранжевый штрихпунктир).
   - Фильтрация по типам меток (выпадающий список: «Все типы», «R128», «Stimulus», «BAD_...» и др.).
   - Быстрые кнопки прыжка по меткам во времени: **«◄ Пред. метка»** и **«След. метка ►»** (окно центрируется на выбранном событии).
   - Кнопка **«Список меток...»** — открывает полную интерактивную таблицу всех меток обоих файлов с поиском и двойным кликом для мгновенного перехода к моменту события.

5. **Скролл и навигация по времени**:
   - Горизонтальный слайдер времени по всей записи.
   - Кнопки пошаговой навигации: `|< Начало`, `<< -10с`, `< -1с`, `+1с >`, `+10с >>`, `Конец >|`.
   - Поле прямого ввода секунд для мгновенного перехода в нужный момент времени.
   - Выбор длины окна просмотра: **1, 2, 5, 10, 20, 30 секунд**.

6. **Масштабирование амплитуды (Gain / Scale)**:
   - Ползунок и кнопки `+` / `-` для изменения размаха в мкВ (1–5000 мкВ).

7. **Метрики в реальном времени**:
   - Автоматический расчет средней корреляции Пирсона $r$ и среднеквадратичной ошибки RMSE (мкВ) между сигналами в текущем видимом окне.

---

## Запуск приложения

### 1. Обычный запуск с пустым окном:
```bash
python file_compareandvis/eeg_compare_app.py
```

### 2. Запуск со сразу загруженными файлами (FIF и SET):
```bash
python file_compareandvis/eeg_compare_app.py \
    data/1929/derivatives/03_bcg/drone/drone_bcg_clean.fif \
    data/1929/derivatives/05_ica/drone/drone_ica_clean.set
```
